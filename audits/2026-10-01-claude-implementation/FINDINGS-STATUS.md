## Found and fixed during this implementation (not in the audit)

- Adding a project with a research horizon failed validation from every entry point (CLI, dashboard, Cowork queue): `research_defaults.providers` was saved as null. Fixed and covered by a test for all three paths.
- A PDF-only report showed as "no research" and its review item never fired. Fixed (see F08).
- After a dashboard restart, an open page got "wrong session token" errors until reloaded. It now renews the token once and retries; a 401 is refused before anything runs, so the retry is safe.
- Node 22+ no longer accepts a folder for `node --test`; `node dashboard/cli.js test` already lists files and is now the `npm test` script.
